# Changelog — SOL Peace Commons 2.3

## Evidence honesty
- EIE excludes sources with zero matched content terms. It no longer pads outputs with research-domain boosts.
- New `NO_ARCHIVE_MATCH` status with transparent empty state; no fabricated intervention attribution.
- Coverage reports number of source URLs and represented archive editions, **not** independent corroboration.
- Preserved source links, citations, limitations, competing hypotheses and private JSON draft export.

## Progressive foundational prompts
- Six self-answered systems questions built into the optional EIE HUD; Next question advances inline without route changes.
- Each question supplies an acceptance test and a supporting archive-research shortcut.
- Foundation progress saved in a local preference; not treated as achievement or agency privilege.

## Local-first and peer reliability
- Local state restoration completes before peer auto-join can cause a render; protects session initialization.
- Connected-peer status distinguished from an open room with no peers.
- Added storage version-change and unexpected-close handlers with backup warnings.
- Kept legacy public handoff and backup schemas; no automatic transfers.
- Advanced PWA cache name to v6; no third-party peer discovery responses cached.

## Retained
- Five complete original research editions and 63 inner routes; 76 public-source entries, 19 case entries and 37 proposed actions.
- MMO learning classes, skills, proof-of-learning XP, review gates, standalone entry point, locally stored research, JSON import/export, optional PWA and Trystero 0.25.3 room API.

## Deliberately not added
- No unverified LLM-generated factual claims or confidence percentages; no autonomous agents or institutional network integrations; no claim of real two-device Trystero interoperability without a hosted test.
