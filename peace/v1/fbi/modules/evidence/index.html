Evidence lab

Five evidence gates: A physical component; B manufacturing origin; C named exporter/importer; D proved military end use; E knowing violation of a specified law. These cannot be collapsed into a single finding.

SHA-256 can establish byte-level file equality, not who authored a file or that its contents are true. The interactive calculator requires JavaScript and compatible browser crypto.

Public official sources: FBI mandate, DOJ Goltsev case, DOJ Shevlyakov case, BIS controls. External links require internet.
